# 安全知识问答助手

一个面向社区/家庭的安全知识问答网页应用，使用 AI 技术普及安全应急知识。

## 功能特点

- **智能问答**：用户打字提问，AI 回答安全知识
- **语音朗读**：点击 🔊 按钮朗读 AI 的回答，方便老人和小朋友使用
- **响应式设计**：适配 PC 浏览器和手机浏览器
- **亲切友好**：AI 以温暖的语气回答问题，像邻居大哥哥大姐姐

## 安全主题覆盖

- 消防安全（火灾预防、灭火器使用、逃生技巧）
- 地震/自然灾害避险
- 急救知识（CPR、止血、烧伤处理）
- 日常安全（用电安全、防溺水、防诈骗）

## 技术栈

- **后端**：Python + Flask
- **前端**：HTML5 + CSS3 + JavaScript（原生，无框架）
- **AI**：MiniMax API (MiniMax-M2.7)
- **语音**：浏览器内置 Web Speech API

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置 API 密钥

在项目根目录创建 `.env` 文件：

```
MINIMAX_API_KEY=你的API密钥
```

### 3. 运行程序

```bash
python app.py
```

### 4. 打开网页

在浏览器中打开：http://localhost:5000

## 使用说明

1. 打开网页后，会显示欢迎语
2. 在底部输入框输入你的安全问题
3. 点击"发送"按钮，AI 会回答你的问题
4. 回答显示后，点击 🔊 按钮可以朗读回答内容
5. 手机和电脑都可以使用
